# ComfyUI 이미지 활용 웹 인터랙션 포트폴리오

채팅형 AI로 상품 이미지를 수정하면서 색상만 바꾸려 해도 포즈·의상·글자가
함께 달라지고, 수정 요청마다 사용량이 차감되는 문제를 확인했습니다.

이를 줄이기 위해 로컬 ComfyUI에서 설정값만 바꿔 같은 조건을 반복 실행하고,
제작한 마스크와 앞뒤 영역 정보를 SVG·CSS·JavaScript에 연결해 입체 배너,
컬러 옵션, 이미지 전환, 사이즈 비교 기능을 구현했습니다.
